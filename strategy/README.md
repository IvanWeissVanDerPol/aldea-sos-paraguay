## Contexto

Aldea SOS Paraguay está recuperándose del impacto reputacional del escándalo de SOS Children's Villages (octubre 2025). La estrategia debe:

1. **Liderar en transparencia** post-escándalo (diferenciador)
2. **Modernizar la recaudación** (donación online, padrinos digitales)
3. **Expandir la base de donantes** (diaspora, tech-for-good)
4. **Fortalecer la marca** (visibilidad, confianza)
