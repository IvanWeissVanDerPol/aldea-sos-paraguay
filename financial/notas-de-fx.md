# Notas de FX — Aldea SOS Paraguay

> Convenciones de tipo de cambio y redondeo para todos los documentos financieros.

## Moneda base

- **Local**: Guaraníes (Gs.)
- **Internacional**: USD
- **Conversión**: 1 USD ≈ 7,300 Gs. (2026)

## Redondeo

- **Guaraníes**: redondear a la centena más cercana (sin decimales)
- **USD**: 2 decimales
- **EUR**: 2 decimales

## Tasa de cambio

- **Fuente**: BCP (Banco Central del Paraguay)
- **Actualización**: mensual para reportes
- **Uso**: documentar la tasa con fecha en cada reporte

## Ejemplo de nomenclatura

```
Total ingresos: Gs. 3,000,000,000 (~$410,959 USD)
```

No:
```
Total ingresos: 3.000.000.000 Gs. o US$ 410.959
```

## Inflación Asunción

- **Tasa anual PY**: ~4% (2026)
- **Ajuste anual**: reportes actualizados por inflación
- **Proyecciones**: ajustar a inflación esperada

## Multi-moneda

- **Recibos**: Gs. (moneda local)
- **Reportes corporativos**: USD
- **Padrinos internacionales**: USD o EUR
- **Aliados corporativos**: USD (estándar)

## Decimales y precisión

- **Sub-Gs**: redondear (no usar decimales)
- **USD**: 2 decimales
- **Porcentajes**: 1 decimal (15.3%)
- **USD grandes**: redondear a millares ($1.5M)

## Ejemplo correcto

```
Donación: Gs. 100,000 (~$13.70 USD)
Donación anual: Gs. 1,200,000 (~$164.38 USD)
Total ingresos: Gs. 3,000,000,000 (~$410,959 USD)
% a programas: 75.0%
Auditoría: USD 0.00 (costo cero, pro bono)
```

## Donaciones pequeñas

- **Min**: Gs. 5,000 (~$0.68 USD)
- **Estándar**: Gs. 100,000 (~$13.70 USD)
- **Generoso**: Gs. 500,000 (~$68.49 USD)
- **Altos padrinos**: Gs. 1,000,000+ (~$137+ USD)

## Costos de transacción

- **Donorbox Standard**: 1.95% + $0.20
- **Stripe**: 2.9% + $0.30
- **Bancard**: 3.5%

## Auditoría

- **Auditor independiente**: pro bono durante 2026
- **Costo anual estimado**: $5,000-15,000 USD si se paga
- **Reportes**: trimestrales + anual
