## Organización del repo (una línea por carpeta)

```
00-start-here/     ← estás aquí — puntos de entrada por audiencia
01-evidence/       ← 15 HTMLs crudos de aldeasinfantiles.org.py + .org + ong.com.py
02-about/          ← nuestro análisis de la organización (dividido del viejo DOSSIER.md)
03-benchmark/      ← comparación con 17 ONGs pares
04-research/       ← catálogo de 939 ONGs + investigación de patrones
05-revenue/        ← 65+ fuentes de ingresos
06-pitch/          ← decks de pitch, one-pagers, FAQ
07-outreach/       ← scripts de email/llamada/redes
08-tech-spec/      ← donación gateway, micrositio de transparencia, specs del portal de apadrinamiento
09-financial/      ← modelo de ingresos + costos + presupuestos
10-strategy/       ← planes 30/60/90 + donor journey + estrategia de competidores
11-policy/         ← carta de salvaguardia + política de protección infantil
12-competitive/    ← análisis profundos de competidores
99-archive/        ← archivos deprecados
META/              ← gobernanza del repo (glosario, registro de riesgos, mapa de stakeholders, action board)
_originals/        ← red de seguridad pre-restructuración
```

Los números son intencionales — el orden de ordenamiento coincide con el orden de lectura. Leer de arriba a abajo.
