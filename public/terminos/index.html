Términos de uso

Lo que aplica a este sitio demo pro-bono. No aplica a la organización ni a su sitio oficial.

1. Qué es este sitio

aldea-sos.paragu-ai.com es una propuesta pro-bono de rediseño del sitio web de Aldeas Infantiles SOS Paraguay. Está mantenido por voluntarios independientes. No es propiedad ni está operado por la organización. La organización no autoriza, supervisa ni financia este sitio hasta que, eventualmente, decida adoptarlo formalmente.

Si la organización adopta este sitio, los términos podrían cambiar. Mientras tanto, los siguientes términos rigen el uso de este demo.

2. Lo que el sitio hace

  • Reproduce información pública sobre la organización.
  • Demuestra un rediseño posible del sitio.
  • Permite simular donaciones, apadrinamientos, postulaciones a voluntariado e interés corporativo — sin procesar nada realmente.
  • Redirige a aldeasinfantiles.org.py para cualquier acción real.

3. Lo que el sitio no hace

  • No procesa donaciones reales. No emite recibos fiscales.
  • No inscribe padrinos reales. No asigna niños reales.
  • No comparte datos con la organización.
  • No hace declaraciones oficiales en nombre de la organización.
  • No usa el RUC, las marcas registradas, ni los activos visuales oficiales de la organización más allá de referencias públicas.

4. Datos personales

Este demo usa localStorage del navegador para simular una una una sesión iniciada. Los datos que completes en los formularios de demo se guardan en tu propio navegador. No se transmiten a ningún servidor más allá de las solicitudes HTTP estándar a este sitio estático.

Si la organización adopta el sitio y lo conecta a su proveedor real de formularios, esa configuración reemplazará este comportamiento. Hasta entonces, los datos de tu navegador son tuyos.

5. Propiedad intelectual

El código fuente de este demo está disponible en el repositorio de GitHub asociado. La información sobre la organización proviene de su sitio oficial y se cita como tal.

Si la organización adopta el sitio, ella pasa a ser la dueña de toda la información y decide cómo licenciarla.

6. Sin garantías

Este demo se ofrece "tal cual", sin garantía de funcionamiento continuo, precisión absoluta, ni disponibilidad. Si encontrás un error, podés reportarlo en el repositorio.

7. Limitación de responsabilidad

Los voluntarios que mantienen este demo no son responsables de decisiones tomadas basándose en información aquí publicada. Toda decisión sobre donación, apadrinamiento, voluntariado o alianza corporativa debe verificarse con la organización directamente.

8. Cambios

Estos términos pueden actualizarse. La fecha de "última actualización" abajo refleja cuándo.

9. Contacto

Para reportar errores en este demo: el repositorio de GitHub del proyecto tiene instrucciones.

Para cualquier asunto sobre la organización, contactá directamente a través de aldeasinfantiles.org.py.
