Terms of use

Applies only to this demo.

1. What this site is

aldea-sos.paragu-ai.com is a pro-bono redesign proposal of the Aldeas Infantiles SOS Paraguay website. Maintained by independent volunteers. Not operated by the organization.

2. What the site does

  • Reproduces public information about the organization.
  • Demonstrates a possible redesign of the site.
  • Simulates donations, sponsorships, volunteer applications, and corporate interest forms.
  • Redirects to aldeasinfantiles.org.py for any real action.

3. What the site does NOT do

  • Does not process real donations. Does not issue tax receipts.
  • Does not register real sponsorships. Does not assign real children.
  • Does not share data with the organization.
  • Does not make official statements on behalf of the organization.

4. Personal data

This demo uses localStorage only. Form submissions are simulated and stored in your browser. Nothing is transmitted to any server beyond standard static-asset requests.

5. Intellectual property

The source code of this demo is available in the associated GitHub repository. Information about the organization is taken from its official site and cited as such.

6. No warranties

This demo is provided "as is" without warranty of continued operation, accuracy, or availability.

7. Limitation of liability

Volunteers maintaining this demo are not responsible for decisions made based on information published here. Any donation, sponsorship, volunteer, or corporate decision must be verified directly with the organization.
