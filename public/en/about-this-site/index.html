About this site

What this is, what it isn't, who built it.

This site at aldea-sos.paragu-ai.com is a pro-bono redesign proposal for the website of Aldeas Infantiles SOS Paraguay. It is maintained by independent volunteers. It is not the official site of the organization.

What it is

  • A demonstration of what a redesigned site could look like.
  • A static site served over HTTPS via GitHub Pages.
  • A reference for whoever eventually takes the work over.

What it isn't

  • Not the official site. Not authorized, endorsed, or funded by the organization.
  • Not a payment processor. All donation and sponsorship forms are simulations.
  • Not a data collector. Everything stays in your browser's localStorage.

How to participate

If you are from the organization and want to discuss adoption, see the contact information on /ANALYSIS.md or the contact form on the official site.

Source code

Available at the GitHub repository listed in the project metadata.
